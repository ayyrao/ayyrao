# Weekly Report v5

## 使用场景
用户要求“写周报”“生成周报”“本周总结”时使用。

## 输入
- 优先读取工作目录下的工作记录：`工作记录/`、`logs/`、`notes/` 等目录中的本周文件；
- 若未找到记录，主动向用户索要要点（项目、完成事项、进行中、风险、下周计划）。

## 工作流程
1. 确认统计周区间（默认本周一至周日）。
2. 收集并去重本周工作条目，按项目分组。
3. 按「已完成 / 进行中 / 问题与风险 / 下周计划」四类归并。
4. 生成 Markdown 周报，要点式表达，避免流水账，每条注明进展与结果。
5. 用户需要文件时，调用 `office-documents` 技能导出 `.docx`，命名 `周报_YYYYMMDD-YYYYMMDD.docx`。

## 约束
- 不编造数据，信息缺失处标注“待补充”。
- 篇幅控制在 1 页内，条目不超过 15 条。
