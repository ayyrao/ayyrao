# 评分与文案规则

## 综合指数

- 由 `scripts/horoscope.py` 根据「星座 + 日期」的 SHA-256 生成，范围 55～95；
- 星级换算：55–64 三星，65–79 四星，80–95 五星；
- 同一星座同一天结果必须一致，避免用户重复询问时得到矛盾答案。

## 爱情 / 事业 / 财运

- 三个分项各自由脚本给出 50～99 的整数；
- 分项只用于组织文案，不要把分数解释为概率或预测；
- 分项之间不要出现自相矛盾的描述（例如“财运极佳”同时“宜节俭到放弃消费”）。

## 幸运元素

- 幸运色从固定色板中选取，使用中文颜色名（如「琥珀橙」）；
- 幸运数字范围 1～9；
- 「宜」「忌」各一条，从脚本词库中选取。

## 文案要求

- 中文，80～150 字；
- 语气轻松、具体，避免“你将会”“一定会”等绝对化表达；
- 结尾固定加一句：`（娱乐向内容，仅供参考）`；
- 不涉及医疗、投资、法律建议。

## 安全

- 不追问生日、身份证号、住址等敏感信息；
- 用户要求“预测具体事件”时，说明本技能只提供娱乐向参考。
